# Cheapest Yes

For every hesitant shopper, Cheapest Yes picks the cheapest incentive that turns "maybe" into "yes": PayPal Pay Later messaging first, then free shipping, then a small add-on, and a small discount only as a last resort. It maximises the merchant's expected profit after incentive cost, not conversion.

**The one rule: list price is the ceiling.** Incentives only add value or lower the price. Nobody ever pays more than list.

Built for the PayPal AI Hackathon (2026). Work in progress.
