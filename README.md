# Cheapest Yes

For every hesitant shopper, Cheapest Yes picks the cheapest incentive that turns "maybe" into "yes". Usually that's PayPal Pay Later: it costs a fraction of a discount, and the merchant pays the extra fee only when the shopper actually uses it. Only when that won't work does it offer free shipping, then a small add-on, and a small discount as a last resort. It maximises the merchant's expected profit after incentive cost, not conversion.

**Pay Later is the cheapest yes: a fraction of a discount, and only charged when the shopper uses it.** On a $240 cart in the US, PayPal's Pay Later rate (4.99% + fixed fee, against 3.49% + fixed fee for standard PayPal Checkout) adds about $3.60. A 10% discount gives away $24 on every order, including to shoppers who would have paid full price.

**The one rule: list price is the ceiling.** Incentives only add value or lower the price. Nobody ever pays more than list.
